# Death's White Knuckle mods

Some of these, being cheats/bypasses/etc, will not get put on Thunderstore, though I'll have them in this repository's GitHub releases.

I run these using the [BepInEx Script Engine](https://github.com/BepInEx/BepInEx.Debug#scriptengine) to make it easier to test in development`

## [Anti Anti-Cheat](./AntiAntiCheat)

Disables disabling leaderboard submission and always allows cheat console commands (no need to run `cheats`).

## [Auto Hop](./AutoHop)

Automatically jumps whenever possible while holding the jump button.

## [Consistent Sensitivity](./ConsistentSensitivity)

Makes grabbing stuff not lower your sensitivity.

## [Developer Mode](./DevMode)

Failed attempt at revealing hidden dev stuff, doesn't really do anything.

## [Pocket Hammer](./PocketHammer)

Automatically puts your hammer in either pocket when loading a level.
Updated version of [BetaTester704's Pocket Hammer](https://thunderstore.io/c/white-knuckle/p/BetaTester704/PocketHammer/).

## [Unlimited Trinkets](./UnlimitedTrinkets)

Lets you load into a level with more trinkets than you should have.
